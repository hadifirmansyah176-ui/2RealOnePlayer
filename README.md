# RealOne Player

Pemutar video Android (min. Android 5.0 / API 21) berbasis Media3 ExoPlayer.

## Cara build lewat GitHub
1. Buat repository baru di GitHub, lalu upload **seluruh isi** folder ini (termasuk folder `.github`).
2. Buka tab **Actions** -> workflow **Build APK** (jalan otomatis saat push, atau klik *Run workflow*).
3. Setelah hijau, buka run tersebut -> bagian **Artifacts** -> unduh `RealOnePlayer-debug-apk`.
4. Ekstrak zip, pasang `app-debug.apk` di HP.

## Fitur
- Daftar semua video otomatis, pencarian judul (ikon kaca pembesar)
- Lanjut putar otomatis jika aplikasi keluar mendadak
- Bass/penguat suara 200% (tombol nada: merah = aktif)
- Kunci layar, tombol volume kanan-tengah, subtitle softsub / file .srt .ass .vtt
